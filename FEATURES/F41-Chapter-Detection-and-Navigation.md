# F41: Chapter Detection and Navigation

## Overview
Automatically detect video chapters from YouTube timestamps or AI-generated chapter detection, creating navigable sections in transcript notes.

## Technical Approach
- Extract YouTube chapter timestamps from description
- AI-powered chapter detection for videos without chapters
- Create table of contents in note
- Timestamp links back to video

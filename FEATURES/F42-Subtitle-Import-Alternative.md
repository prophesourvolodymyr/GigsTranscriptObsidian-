# F42: Subtitle Import Alternative

## Overview
For YouTube videos with existing subtitles/captions, offer option to import subtitles instead of transcribing (free, instant alternative).

## User Story
As a user, I want to use existing YouTube subtitles when available, so that I can save time and API costs for videos that already have captions.

## Technical Approach
- Detect subtitle availability
- Offer subtitle import as alternative
- Download and parse SRT/VTT formats
- Convert to transcript format
- Note limitation: auto-generated captions less accurate

## Priority
**Should-Have** 🟡 (Phase 2)

## Estimated Effort
**3-4 days**

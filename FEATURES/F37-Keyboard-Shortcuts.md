# F37: Keyboard Shortcuts

## Overview
Customizable keyboard shortcuts for common plugin actions.

## Default Shortcuts
- `Ctrl/Cmd + Shift + T`: Transcribe from clipboard
- `Ctrl/Cmd + Shift + V`: Paste and transcribe
- `Ctrl/Cmd + Shift + Q`: Open queue

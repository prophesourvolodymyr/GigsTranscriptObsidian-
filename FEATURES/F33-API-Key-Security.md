# F33: API Key Security

## Overview
Secure storage and handling of API keys using OS-level encryption (Keychain on macOS, Credential Manager on Windows).

## Technical Approach
- Electron's safeStorage API
- Never log API keys
- Masked display in UI
- Validation on save

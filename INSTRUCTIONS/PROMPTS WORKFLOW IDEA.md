# PROMPTS WORKFLOW
## How to Use the 4-Prompt System for AI Development

---

## 🎯 PURPOSE

This document explains the **4-prompt workflow** for building applications with AI assistance. Each prompt serves a specific phase of development.

---

## 📋 THE 4 PROMPTS

### **PROMPT-1: GENERAL PLANNING**
**When to use:** Start of project
**What it does:** AI creates complete architecture, feature list, and TODO breakdown
**Output:**
- Feature documents (F1, F2, F3...)
- Comprehensive TODO list in `PROGRESS.md` (100+ tasks)
- API research and documentation
- Icon manifest
- Architecture plan

**User action:** Copy PROMPT-1 content → Paste into AI → AI creates planning documents

---

### **PROMPT-2: IMPLEMENTATION**
**When to use:** After planning is complete
**What it does:** AI implements the TODO tasks from `PROGRESS.md`
**How it works:** AI executes all tasks systematically

**User action:** Copy PROMPT-2 content → Paste into AI → AI starts building

---

### **PROMPT-3: REFINEMENT**
**When to use:** After implementation is complete
**What it does:** AI reviews every feature and polishes to excellence
**Focus:**
- Fix rough edges
- Enhance UX
- Optimize performance
- Ensure consistency
- Handle edge cases

**User action:** Copy PROMPT-3 content → Paste into AI → AI refines everything

---

### **PROMPT-4: REVERSE ENGINEERING**
**When to use:** After refinement
**What it does:** AI analyzes architecture and reconstructs with best practices
**Focus:**
- Compare to world-class apps
- Identify architectural improvements
- Apply industry patterns
- Achieve reference-quality code

**User action:** Copy PROMPT-4 content → Paste into AI → AI elevates to excellence

---

## 🔄 COMPLETE WORKFLOW

```
1. PROMPT-1 (Planning)
   → Creates: Features, TODOs, Architecture

2. PROMPT-2 (Implementation)
   → Builds: All features from TODO list

3. PROMPT-3 (Refinement)
   → Polishes: Every detail to perfection

4. PROMPT-4 (Excellence)
   → Reconstructs: World-class architecture
```

---

## 🎯 WHAT EACH PROMPT CREATES

### Prompt 1 Output:
- `/FEATURES/F1-[Name].md` through `/FEATURES/F30+.md`
- `/WORK/PROGRESS.md` (100+ TODO items)
- `/FEATURES/ICON-MANIFEST.md`
- `/FEATURES/API-ENDPOINT-MAP.md`
- Complete technical architecture

### Prompt 2 Output:
- Complete application code
- All features implemented
- Git commits (clean history, no AI branding)
- Updated `PROGRESS.md` with completed tasks

### Prompt 3 Output:
- `/FEATURES/REFINEMENT-REPORT.md`
- Polished UI/UX
- Optimized performance
- Fixed edge cases
- Consistent design

### Prompt 4 Output:
- `/FEATURES/ARCHITECTURE-ANALYSIS.md`
- Reconstructed components
- Better patterns applied
- Before/after metrics
- Lessons learned document

## 💡 KEY PRINCIPLES

### Built Into All Prompts:

**Creative Thinking:**
- AI thinks outside the box
- Enhances requirements
- Adds missing features
- Improves solutions

**Git Workflow:**
- Regular commits
- Clean commit messages
- NO AI branding (Claude, AI, Assistant, etc.)

- Production-ready code
- Full TypeScript types
